====================================================================
 Bike Geo — 自行车几何线稿 / 多车对比
 分享版 · 使用说明（README）
====================================================================

一、这是什么
--------------------------------------------------------------------
Bike Geo 是一个打开即用的单页网页工具。

你只需输入一台自行车"必要的几何输入"，程序会按标准自行车几何关系
反推其余结果（Reach、Stack、Wheelbase、Trail、有效上管等），并在点阵纸上
用线条画出车架侧视图。

最多可以同时输入 3 台车的数据，每台车用不同颜色叠画在一起
（A = 黑色、B = 淡蓝、C = 活力橙），轮胎环带会用该车颜色的淡色填充，
并附带一张"A/B/C 数值 + 相对 A 车差值"的对比表。适合比较不同车架尺寸、
不同车型，或调整参数看几何变化。

另有可选的 Personal Fitting Area：可记录把立、坐高/座管与牙盘数据，
叠加绘制并进入对比表；全部留空时不影响车架几何，也不改变原有界面。

主要特点：
  · 无需安装、无需联网、无需构建工具，双击即可使用
  · 11 个必要输入 → 12 个自动补全参数
  · 鼠标悬停任一参数，画布上对应线条高亮并显示尺寸标注
  · 最多 3 台车彩色叠画对比（轮胎按车色淡染）+ 完整的数值差表
  · 可切换"后轴对齐 / 地面线对齐"两种叠画基线
  · 输入可存成命名模板（保存在本机浏览器），随时载入 / 删除
  · 模板可导出为 JSON / 导入，换设备、换浏览器、重开也能恢复
  · Personal Fitting Area：可选记录把立、坐高/座管、牙盘数据并叠加绘制
  · 可导出矢量 SVG（含各车颜色与点阵纸），可进 Illustrator / Figma / CAD


二、怎么打开
--------------------------------------------------------------------
Windows / macOS：
  解压后双击 index.html，用默认浏览器打开即可。
  建议使用较新版本的 Chrome / Edge / Firefox / Safari。

如果浏览器因安全策略不允许直接打开本地文件，可以在本文件夹内
启动一个本地静态服务器（需要 Python）：

    python -m http.server 8000

然后浏览器访问：

    http://localhost:8000

整个工具完全离线运行。界面上的"在线导入"按钮只是预留位置，当前不可用。


三、界面与操作
--------------------------------------------------------------------
1) 左侧：点阵纸画布 + 车架线稿。

2) 右侧面板：
   · A / B / C 标签：最多 3 台车。点击标签切换"当前编辑的车"；
     "×"删除该车（至少保留 1 台）；"＋ Add bike"添加一台
     （自动使用下一个未用预设；满 3 台后按钮变灰）。
   · Save template / 模板下拉框：点 "Save template" 把当前选中车的全部
     输入（含个人设定）存成命名模板（保存在本机浏览器 localStorage，不上传）；
     之后从 "Templates…" 下拉框选择即可载入，右侧 "×" 删除选中的模板。
     切换 A/B/C 或载入 Preset 时，模板选择会自动重置。
   · Export templates / Import templates：把全部模板导出为一个 JSON 文件，
     或在新设备 / 新浏览器中导入。同名模板会询问"是否覆盖"，选择取消则
     自动改名（如 "xxx (2)"）保留两份。
   · Parameters：当前选中车的 11 个必要输入，可直接修改；
     下方 Compensated 是自动计算出的参数（灰色，不可编辑）；
     再下方的 Personal Fitting Area 是可选的个人设定（见第六节）。
   · Compare：有 2 台以上车时可用；列出全部参数在 A/B/C 上的数值，
     并显示 B、C 相对 A 车的差值。任一台车填写了个人设定时，表格末尾
     会出现 "Personal fitting" 分组，未填写的车显示 "—"。
   · 顶部 Preset：预设车型，只作用于当前选中的车；修改任意输入后
     该车会变为 "Custom"。
   · 顶部 Export SVG：把当前画布导出为矢量 SVG 文件。
   · 画布右上角状态条：显示当前车的轮径 / 胎宽 / 轮胎外径。

3) 悬停参数：
   鼠标移到右侧任意参数行（包括 Compare 表行），画布上对应的
   车管/轮组会高亮（其它线条淡出）；Parameters 模式下还会显示当前
   车的尺寸标注。鼠标移开即恢复。

4) 画布右下角 "On the ground" 按钮（对齐基线切换）：
   默认按"后轴对齐"叠画——所有车的后轴重合同一点，方便比较车架
   几何本身。按下该按钮后改为按"车轮最低线（地面线）"对齐：不同
   轮径/胎宽的车会按照真实的离地高度摆放，能直观看出五通高度、
   车架整体高度的差异。按钮再次按下即恢复后轴对齐。


四、必要输入（11 项）
--------------------------------------------------------------------
Wheel BSD         轮圈胎圈座直径（mm）。
                  常见值：622 = 700C / 29"，584 = 650B / 27.5"，
                          571 = 650C，559 = 26"
Tire width        轮胎截面宽度（mm）。模型中同时作为胎侧高度。
Chainstay length  后下叉长：五通中心 → 后轴中心（mm）。
BB drop           五通下沉量：轴心水平线 → 五通中心的垂直距离（mm）。
Seat tube length  立管长：五通中心 → 立管顶部（mm）。
Seat tube angle   立管角度：相对水平线（°）。
Head tube angle   头管角度：相对水平线（°）。
Head tube length  头管长度（mm）。
Front center      五通中心 → 前轴中心的直线距离（mm）。
Fork offset       前叉偏移（Rake）：前轴到转向轴线的垂直距离（mm）。
Fork length       前叉长度：前轴 → 头管下沿的直线距离（mm）。

说明：Reach、Stack、Wheelbase 不是输入，而是上述几何推导出的结果。
前轴位置由 Front center + BB drop 确定；车头位置由头管角度/长度、
Fork length、Fork offset 从前轴反推；Wheelbase 则由"后下叉 + BB drop"
与"前中心 + BB drop"两次水平投影相加得到。


五、自动补全参数（12 项）
--------------------------------------------------------------------
Reach                    五通垂线 → 头管顶部中心的水平距离
Stack                    五通中心 → 头管顶部中心的垂直距离
Stack / reach ratio      堆高 / 前伸比
Tire outer radius        轮胎外半径
Tire outer diameter      轮胎外径
BB height                五通离地高度
Chainstay (horizontal)   后下叉水平投影长度
Front center (horizontal)  前中心距离的水平投影
Effective top tube       有效上管长（水平）
Wheelbase                轴距：前后轴的水平距离
Trail                    拖曳距
Mechanical trail         机械拖曳距


六、个人设定（Personal Fitting Area，可选）
--------------------------------------------------------------------
位置：参数面板 "Compensated" 下方，虚线框内的 "Personal Fitting Area"。
所有字段都可以留空；留空时不参与绘图与对比，也不影响车架几何结果。
填写后会以当前车颜色叠加绘制在画布上。

Stem（把立）：
  Stem length          把立长度：从头管顶部沿把立方向量起。
  Stem angle           把立角度：相对"舵管垂线"测量；0° = 垂直舵管
                       伸出，正角度沿舵管向上。
  Stem reach           从把立末端向舵管作垂线，该垂线的长度。
  Stem stack           把立线在舵管轴线上的投影长度。

  Length + Angle 与 Reach + Stack 是同一组把立的两种表示，可双向换算：
  修改前一对中的任一字段，后一对自动更新；反之亦然。只填一半时不会
  绘制把立，填齐一对后自动出现。

Saddle / Seatpost（坐高 / 座管）：
  Saddle height        坐垫高度：五通中心沿立管到坐垫顶面的距离。
  Seatpost length      座管总长度。
  Seatpost over frame  派生 = Saddle height − Seat tube length
                       （坐垫高出立管顶部的部分）
  Seatpost insert      派生 = Seatpost length − Seatpost over frame
                       （座管插入车架内的长度）

  两个派生值只是结果，不可编辑。若出现负值，会用橙色显示，表示当前
  坐高 / 座管长度组合在物理上不成立。

Crankset（牙盘）：
  Crank length         曲柄长度（mm），绘制为从中轴垂直向下的线段。

示例（Tarmac 49）：
  Saddle height 700、Seat tube length 447 → Seatpost over frame 253.0；
  Seatpost length 350 → Seatpost insert 97.0。


七、重点：胎宽 → 轮胎外径 的计算逻辑
--------------------------------------------------------------------
（这一节专门解释"为什么 +1mm 胎宽 = +2mm 外径"）

本工具采用 Bike Insights 等车架几何表通用的"名义尺寸"模型：

    轮胎外径 OD = BSD + 2 × Tire width

推导思路：
  · BSD（胎圈座直径）是轮胎安装的基准圆直径；
  · 模型中轮胎截面宽度 = 胎侧高度（side-wall height）；
  · 轮胎外径 = 基准圆 + 两侧各一层胎侧高度 = BSD + 宽度 + 宽度；
  · 所以：胎宽每 +1mm，轮胎半径 +1mm，外径（直径）+2mm。

两个校验点（与 Bike Insights 公开数据一致）：
  · 700C（BSD 622）+ 26mm 胎宽 → 622 + 26×2 = 674mm
  · 650B（BSD 584）+ 47mm 胎宽 → 584 + 47×2 = 678mm

在页面里如何自己验证：
  · 顶部状态条会显示，例如 "700C / 29" · 26 mm · OD 674.0 mm"；
  · 参数面板中 "Tire outer diameter" 一行显示 674.0；
  · 鼠标悬停这一行，会在前轮上画出直径尺寸线 Ø 674.0 mm；
  · 把 Tire width 从 26 改成 27：外径变为 676.0，外半径变为 338.0；
  · 预设选 "650B gravel (47 mm)"，可直接看到 OD 678.0 mm。

关于质疑（如实说明）：
  · 上述是"名义计算"。真实轮胎装车后的外径还会受轮圈内宽、胎压、
    花纹、胎体结构、品牌公差等影响，同一标称尺寸的实测值可能相差
    几毫米；实际截面宽度也不完全等于胎侧高度。
  · 本工具与 Bike Insights 的公开几何表保持一致，采用名义 1:2 模型，
    因此能对上它们给出的 Tire Outer Diameter。
  · 如果你有某条胎的实测外径，可以反推"等效胎宽"：

        等效胎宽 = (实测外径 − BSD) ÷ 2

  · 本工具里的胎宽输入即"名义胎宽"；如需按实测外径绘图，请用上面的
    公式换算后再填入。


八、预设车型
--------------------------------------------------------------------
  · Tarmac SL7 Comp '23 (49)
  · CruX Expert '25 (49)
  · Classic road (56)
  · 650B gravel (47 mm)     ← 用于验证 650B × 47 = OD 678

九、对比模式（2 ~ 3 台车）
--------------------------------------------------------------------
  · 点击 "＋ Add bike" 增加一台：自动使用下一个未用预设，并自动切到
    Compare 视图；
  · 三台车按后轴对齐叠画：A = 黑色、B = 淡蓝、C = 活力橙，
    画布左上角会显示颜色图例；
  · 每台车的轮胎（两个同心圆之间的环带）会用该车颜色的淡色填充，
    多车叠在一起时靠颜色和淡色环带区分，不会糊成一片；
  · 右下角 "On the ground" 按钮：切换叠画基线。默认后轴对齐；按下后
    按车轮最低线（地面线）对齐，能看出不同轮径/胎宽带来的五通高度与
    车架高度差异；再按一次恢复；
  · Compare 表列出全部 23 项（11 个输入 + 12 个补全参数）在 A/B/C 上
    的数值，并显示 B、C 相对 A 车的差值；
  · 任一台车填写了 Personal Fitting 数据时，对比表末尾会追加
    "Personal fitting" 分组（把立、坐高/座管、牙盘），未填写的车显示 "—"；
  · 悬停 Compare 表中的任意一行，三台车上对应的线条会同时高亮；
  · 提示：不同轮径 / 胎宽的车，车轮大小与地面虚线会不同，这是有意
    保留的信息（按后轴对齐，而不是强行把地面线对齐）。


十、导出与深链
--------------------------------------------------------------------
Export SVG：
  浏览器会下载 bike-geo.svg，包含所有车的颜色和点阵背景；
  可用 Illustrator / Inkscape / Figma / CAD 打开并继续编辑。

Export templates / Import templates：
  模板栏下方的两个文字按钮。Export templates 会把当前浏览器里的全部
  模板（含个人设定字段）导出为 bikegeo-templates-日期.json；
  Import templates 读取该 JSON 并合并到当前浏览器，同名模板会询问是否
  覆盖，取消则自动改名保留两份。适合换设备、换浏览器或备份。

深链（在 index.html 后面追加参数）示例：

    index.html?preset=crux
    index.html?compare=crux,classic
    index.html?compare=crux&view=params&param=stack
    index.html?compare=crux,classic&align=ground

  · preset  指定 A 车预设
  · compare 追加对比车（逗号分隔，可多个，最多 3 台）
  · view    params 或 compare，打开时显示的视图
  · param   打开时预先高亮的参数（车架参数或个人设定键名均可）
  · align   ground 时按地面线对齐（否则按后轴对齐）


十一、常见问题
--------------------------------------------------------------------
问：双击打不开或白屏？
答：请使用较新的 Chrome / Edge / Firefox / Safari；或按第二节用本地
    服务器方式打开。

问：改了胎宽，车架看起来几乎没变？
答：胎宽主要影响车轮外径（半径 ±1mm 对应直径 ±2mm），车架几何本身
    不变。外径请看 "Tire outer diameter" 一行。

问：Compare 表里的 +8、-1.25 是什么？
答：是相对 A 车的差值，单位与该行参数一致（mm 或 °）。

问：为什么 Reach / Stack / Wheelbase 是结果而不是输入？
答：这三项是车架几何的结果量。本工具改用更接近设计过程的输入：后三角
    （后下叉、BB drop）、车头（头管角度/长度）、前叉（Rake、前叉长度）
    与前中心。Reach/Stack 由车头位置反推，Wheelbase 由前后两个水平投影
    相加得到，避免同时给 Reach/Stack 又给前叉长度/Rake 的过约束矛盾。

问：右下角 "On the ground" 按钮是做什么的？
答：切换叠画基线。默认按后轴对齐（方便比较车架几何）；按下后改成
    按车轮最低线（地面线）对齐，能看出轮径/胎宽造成的五通高度与
    整车高度差异；再按一次恢复后轴对齐。

问：数据会上传吗？
答：不会。本工具完全在本地浏览器中运行，没有统计、没有联网请求。
    "在线导入"按钮只是预留位置，当前不可用。

问：能保存我调好的车吗？
答：可以。点 "Save template" 给当前车的全部输入（含 Personal Fitting）
    起个名字保存，之后从 "Templates…" 下拉框选择即可载入；选中的模板
    可按右侧 × 删除。也可以随时用 Export SVG 保存当前画布。

问：保存的模板存在哪里？会丢吗？换设备怎么办？
答：模板保存在本机浏览器的 localStorage 中（不会上传、不在文件里）。
    换浏览器 / 换电脑 / 清除浏览器数据后会丢失。用模板栏下方的
    "Export templates" 把全部模板导出成 JSON 文件，在新设备上点
    "Import templates" 导入即可恢复（同名模板会询问是否覆盖）。
    若浏览器禁用了本地存储，模板仅在本次会话有效，但导出仍可用。

问：Personal Fitting Area 的数值会改变车架几何吗？
答：不会。把立、坐高/座管、牙盘都是可选的骑乘设定，只叠加绘制在
    画布上并进入对比表；Reach / Stack / Wheelbase / Trail 等车架结果
    不受影响。留空则不绘制、不参与对比。


十二、分享与隐私
--------------------------------------------------------------------
  · 本文件夹只包含程序本身（HTML / CSS / JS）、测试、截图和说明文档；
  · 不含作者姓名、账号、邮箱、本机路径、浏览器记录等个人信息；
  · 模板只保存在使用者本机浏览器的 localStorage 中，不在分享文件内；
  · 导出模板得到的 JSON 只含模板名称、几何输入与个人设定数值，
    不含设备信息、账号、浏览器路径；分享该文件前请确认是否愿意
    公开自己的把立/坐高等 fitting 数据；
  · 截图只是程序界面本身，不含桌面或浏览器其他内容；
  · 分享方法：压缩整个文件夹 → 发给朋友 → 对方解压后双击 index.html；
  · 也可以把整个文件夹上传到任意静态网站托管（GitHub Pages / Netlify /
    Vercel 等）作为网页分享。
